T1 VBM V2 全流程使用说明

流程： G0 环境检查 → Step1 输入 QC/解压/Manifest → calibration → Step2 CAT12 → Step3 SPM + Design QC → Step4 FWE/探索性结果 + Table1 → HTML QC + Methods 参数摘要。

1. 首次运行

addpath('G:\SSD_dyf\T1_vbm')
C = t1vbm_config();
t1vbm_env('checkspm', C)
t1vbm_step1_unzip(C)
t1vbm_calibrate(C)

校准结果写入 log/calibration.mat。随后按校准结果设置 nproc。

2. CAT12

run_all('from','step2','nproc',8)

这里的 8 只是示例，不是固定推荐值。CAT12 完成判定不再只依赖 mwp1；每例需要 mwp1、mwp2、y_ 三类输出均存在且非空，并建立 manifest/cat12_done/<subject>.done。

3. 统计模型

项目V2 设置
组间模型two-sample t-test，unequal variance
协变量Age, Sex, EducationYears
Sex0/1 coding
连续协变量默认中心化
显式 mask全样本 mean GM probability > 0.20
平滑FWHM 8 mm（可配置）
Primaryvoxel-level FWE p < 0.05
Exploratoryvoxel-level uncorrected p < 0.001 + ≥10 voxels

4. 断点与失败恢复

log/pipeline_state.mat 记录 step1–4 的 running/complete/failed 状态。CAT12 subject 状态记录在 manifest 中。修复失败例后可使用：

run_all('from','step2')
run_all('from','step3','until','step3')
run_all('from','step4','until','step4')

6. 兼容性

t1vbm_util.m 保留为兼容层，因此旧脚本中调用 t1vbm_util(...) 不需要立即修改。新的模块分别承担 environment、files、log、table 和 manifest 功能。

注意：本版本已经把“FWE 阈值”和“uncorrected exploratory threshold”严格分开。正式论文中应根据预先设定的统计分析方案选择并如实报告主要推断标准。

V2.1 Windows 后台 CAT12

Step2 默认使用隐藏 MATLAB worker。每个 subject 启动一个 matlab -batch worker，由 PowerShell 的 Start-Process -WindowStyle Hidden 启动；worker 内部 CAT12 使用 nproc=0，避免 CAT12 再次创建可见 MATLAB Command Window。监督状态使用 .running/.done/.fail 文件，不再依赖 CAT12 父进程的 Unknown/Unprocessed 统计。

推荐运行：C=t1vbm_config('nproc',12); run_all('from','step2','until','step2','nproc',12)。

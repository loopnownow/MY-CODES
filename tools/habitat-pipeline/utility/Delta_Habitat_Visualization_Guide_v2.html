2. 运行顺序总览

阶段 0 数据加载 (data_loader.py) ↓ 阶段 1 预处理 (preprocessing.py) ├── 重采样（1×1×1 mm B-Spline） ├── N4 偏置场校正（可选，MRI） ├── 灰度归一化（minmax / zscore） └── Mask 对齐 + 验证 ↓ → plot_preproc_qc("pre") / plot_preproc_qc("post") 阶段 2 非刚性配准 (registration.py) ├── Translation → Affine → SyN 三阶段级联 ├── Mask 引导优化 └── QC: Dice + Hausdorff + warped mask 保存 ↓ → plot_registration_qc() 阶段 3 生境划分 (habitat.py) ├── cohort_mode=True：池化基线体素特征 → 全局 Scaler+PCA+KMeans ├── 单患者模式：独立优化 K └── 生成 K 个 Habitat Mask（基线空间） ↓ → plot_habitat_overlay() plot_habitat_intensity_distribution() ← NEW plot_habitat_delta() ← NEW ↓（全队列完成后） plot_cohort_habitat_consistency() ← NEW plot_habitat_feature_space() ← NEW（需 feature_matrix） 后续 特征提取 → Delta 计算 → 筛选 → 统计建模

3. 配置区说明（顶层软编码）

所有可调参数集中在脚本顶部 VIZ_CONFIG 字典。修改一处即可全局生效；也可通过各函数的 override_config 参数临时覆盖单次调用。

基础显示

dpi：输出分辨率（默认 200；论文图用 300）
robust_percentiles：抗 outlier 显示范围（默认 2~98）
save_format："png" 或 "pdf"
show_colorbar / show_legend：可选元素开关

切片策略

slice_strategy："mid"（中位数）或 "percent"（百分位）
slice_percent：仅 "percent" 模式生效（默认 0.5）
三个正交切片索引 (z, y, x) 由 get_slice_indices() 统一计算

Mask / Contour

mask_contour_color：等高线颜色（默认红色）
mask_contour_linewidth：线宽（默认 1.8）
mask_contour_alpha：透明度（默认 0.85）

Habitat Overlay

colormap_habitat：颜色映射（默认 tab10；色盲友好用 Set2）
habitat_overlay_alpha：叠加透明度（默认 0.55）
cohort_panel_cell_size：队列面板单格大小（默认 (3,3)）

t-SNE 参数

tsne_perplexity：困惑度（默认 30）
tsne_random_state：随机种子（默认 42，保证可复现）
tsne_max_voxels：最大体素采样数（默认 5000，防内存溢出）

路径与命名

output_root：输出根目录（默认 OUTPUT_ROOT/qc_reports/viz）
filename_template：文件名模板，支持 {patient_id}、{stage}、{suffix}、{ext}

# 示例：临时覆盖参数（不修改全局配置）
plot_habitat_overlay(
    patient_id="001",
    override_config={
        "dpi": 300,
        "habitat_overlay_alpha": 0.7,
        "colormap_habitat": "Set2",   # 色盲友好
    }
)

4.2 plot_preproc_qc BUG-1/3 修复

plot_preproc_qc(patient_id: str, timepoint: str = "pre", override_config: dict = None) → Optional[str]

输出：1 行 × 3 列（Axial / Sagittal / Coronal），mask 红色 contour 叠加。

BUG-1 修复：mask contour 切片对齐
v1.0 代码将 slice(None) 传入 ax.contour()，导致三维数组直接传入报错（或因 matplotlib 内部截断而静默失败，contour 消失）。

修复方式：新增 _orthogonal_slices(arr, z, y, x) 辅助函数，图像与 mask 均调用同一函数提取对应视图的二维切片，严格对齐。
BUG-3 修复：sagittal / coronal 背景图错误
v1.0 所有视图的背景均使用 arr[z]（axial 切片），Sagittal / Coronal 面板实为 axial 图的重复。

修复方式：Sagittal 使用 arr[:, y, :]，Coronal 使用 arr[:, :, x]。mask 切片同步修正。 
# ── v1.0 错误写法（BUG-1 + BUG-3）──────────────────────
views = [
    (arr[z], f"Axial z={z}"),
    (arr[:, y], f"Sagittal y={y}"),    # BUG-3：arr[:, y] = axial 不是 sagittal
    (arr[:, :, x], f"Coronal x={x}")
]
# BUG-1：mask contour 传入三维数组
ax.contour(m_arr[z if title.startswith("Axial") else
                 (slice(None) if "Sagittal" in title else slice(None))], ...)

# ── v2.0 修复写法 ─────────────────────────────────────
def _orthogonal_slices(arr, z, y, x):
    """从 (D, H, W) 数组提取三个正交二维切片"""
    return [
        arr[z, :, :],    # Axial    → H×W
        arr[:, y, :],    # Sagittal → D×W
        arr[:, :, x],    # Coronal  → D×H
    ]

img_slices = _orthogonal_slices(arr,   z, y, x)
msk_slices = _orthogonal_slices(m_arr, z, y, x)  # 与图像切片严格对齐

for idx, (ax, img_sl, title) in enumerate(zip(axes, img_slices, view_titles)):
    ax.imshow(img_sl, cmap="gray", vmin=vmin, vmax=vmax, origin="lower")
    if msk_slices is not None:
        ax.contour(msk_slices[idx], levels=[0.5], ...)  # 二维切片，正确

# ── v2.0 修复写法 ─────────────────────────────────────
diff      = arr_f[z, :, :] - arr_r[z, :, :]
diff_vmax = float(np.percentile(np.abs(diff), 98))

]

6. 阶段三：生境可视化（核心）

为什么 Habitat 可视化是最关键的 QC 环节
Delta 特征的可比性（跨时间点、跨患者）完全依赖于 Habitat 划分的语义一致性。视觉检查是目前验证聚类质量最直接、最可信的手段，同时也是论文 Figure / Supplementary 的必要内容。v2.0 提供 5 种互补的 Habitat 可视化，覆盖从单患者 QC 到全队列验证的完整需求。

6.2 plot_habitat_intensity_distribution NEW

plot_habitat_intensity_distribution(patient_id: str, override_config: dict = None) → Optional[str]

目的：验证 K-Means 聚类是否捕捉了真实的强度异质性，而非随机分区。
输出：逐 Habitat 小提琴图（内嵌中位数线），每个 Habitat 独立着色，Y 轴为归一化体素强度。

判读要点
• 不同 Habitat 的分布应有明显的中位数差异或形状差异（尖峰 vs 双峰 vs 宽尾）
• 如果所有 Habitat 的分布几乎完全重叠，说明聚类主要基于空间位置而非强度特征，需要检查特征归一化步骤
• 该图是论文 Supplementary Figure 的标准内容 
parts = ax.violinplot(
    intensity_data,
    positions=range(1, k + 1),
    showmedians=True,
    showextrema=True,
)
# 按 Habitat 颜色着色
for patch, color in zip(parts["bodies"], colors):
    patch.set_facecolor(color)
    patch.set_alpha(0.75)
parts["cmedians"].set_color("black")
parts["cmedians"].set_linewidth(2)

输出目录：habitat_viz/p{id}_habitat_intensity_dist.png

plot_habitat_delta(patient_id: str, override_config: dict = None) → Optional[str]

6.4 plot_cohort_habitat_consistency NEW

plot_cohort_habitat_consistency(all_patient_ids: List[str], k: int, override_config: dict = None) → Optional[str]

目的：验证 cohort_mode=True 时，相同 Habitat 编号在不同患者中代表相同组织表型（跨患者语义一致性）。
输出：N×K 网格，行=患者，列=Habitat 编号，每格=该患者该 Habitat 的轴位中心切片 overlay。

注意
该函数应在全队列所有患者均处理完毕后调用（run_visualization(run_cohort_panel=True)），而非逐患者调用。患者数量 N 较大时输出图像会较长，建议保存为 PDF 格式（override_config={"save_format": "pdf"}）。 
# 调用示例
plot_cohort_habitat_consistency(
    all_patient_ids=["001", "002", "003", ...],
    k=3,
    override_config={
        "cohort_panel_cell_size": (3, 3),
        "save_format": "pdf",          # 推荐 PDF，患者多时不失真
    }
)

输出：habitat_viz/pcohort_habitat_consistency.png/pdf

6.5 plot_habitat_feature_space（t-SNE）NEW

plot_habitat_feature_space(patient_id: str, feature_matrix: np.ndarray, labels: np.ndarray, override_config: dict = None) → Optional[str]

目的：在高维特征空间中验证 Habitat 分离度，是论文 Supplementary 中展示聚类质量的标准图。
输出：2D t-SNE 散点图，按 Habitat 标签着色，支持随机下采样（默认最多 5000 体素）。

调用时机
该函数需要 feature_matrix（归一化后的体素级特征矩阵）和 labels（聚类标签），建议直接在 habitat.py 的聚类步骤完成后调用，避免重新计算特征。 
# 在 habitat.py 中集成
from visualize_pipeline import plot_habitat_feature_space

# ... 聚类完成后 ...
plot_habitat_feature_space(
    patient_id="001",          # 或 "cohort"（全队列池化特征）
    feature_matrix=X_scaled,    # (N_voxels, N_features)，已归一化
    labels=kmeans.labels_,      # (N_voxels,)
    override_config={
        "tsne_perplexity": 50,   # 样本多时可适当增大
        "tsne_max_voxels": 8000,
    }
)

# 依赖：scikit-learn（pip install scikit-learn）
# 若未安装，函数会 logger.error 并 return None，不影响其他流程

8. 使用方式

方式一：直接运行（最常用）

# 修改脚本顶部 VIZ_CONFIG 后直接运行
python visualize_pipeline.py

方式二：notebook 或其他脚本中导入（推荐调试）

from visualize_pipeline import run_visualization, plot_habitat_overlay

# 只跑前 3 个患者的 registration + habitat
run_visualization(
    patient_ids=["001", "002", "003"],
    stages=["registration", "habitat"],
    run_cohort_panel=True,
    cohort_k=3,
)

# 单函数调用 + 临时覆盖（论文图 300 dpi）
plot_habitat_overlay(
    patient_id="001",
    override_config={"dpi": 300, "colormap_habitat": "Set2"}
)

方式三：集成到 pipeline.py debug 模式（生产推荐）

from visualize_pipeline import (
    plot_preproc_qc, plot_registration_qc,
    plot_habitat_overlay, plot_habitat_intensity_distribution,
)

def process_single_patient(pid, debug=False):
    # ... 预处理 ...
    if debug:
        plot_preproc_qc(pid, "pre")
        plot_preproc_qc(pid, "post")

    # ... 配准 ...
    if debug:
        plot_registration_qc(pid)

    # ... Habitat 划分 ...
    if debug:
        plot_habitat_overlay(pid)
        plot_habitat_intensity_distribution(pid)
